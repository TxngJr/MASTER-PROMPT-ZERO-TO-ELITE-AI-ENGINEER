# Chapter 44 Solutions — Key Ideas

- IoU measures intersection divided by union and is central to localization matching.
- NMS keeps high-scoring boxes and removes sufficiently overlapping lower-scoring duplicates.
- one-stage detectors predict densely; two-stage detectors refine proposals.
- semantic segmentation labels classes per pixel, while instance segmentation separates object identities.
- U-Net skip connections recover high-resolution spatial detail during decoding.
