# Chapter 38 Solutions — Key Ideas

- Bellman equations express recursive consistency between current value and future return.
- Q-Learning bootstraps toward a greedy next-state target and is off-policy.
- DQN stabilizes neural Q-learning with replay and a target network.
- policy gradients optimize sampled action log-probabilities weighted by returns/advantages.
- PPO clips the policy probability ratio to discourage overly large updates from the same batch.
