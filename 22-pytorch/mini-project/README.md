# Mini Project — PyTorch Training Harness

Build a reusable trainer for sklearn digits.

Required:
- train/validation/test split
- TensorDataset/DataLoader
- configurable device
- MLP model
- CrossEntropyLoss
- AdamW
- train/eval loops
- validation checkpoint selection
- final test once
- state_dict save/load
- JSON metrics
- seed control

GPU extension:
- measure batch time on RTX GPU
- compare batch sizes
- inspect memory_allocated/reserved
