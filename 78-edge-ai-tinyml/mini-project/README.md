# Mini Project — Edge Deployment Budget Lab

Choose a tiny classifier/regressor and build a deployment report with:
- parameter/model bytes
- peak activation estimate
- runtime/tensor-arena budget
- operator inventory
- INT8 quantization error
- warm latency
- estimated energy/inference
- sensor/input window memory
- fallback/unsupported operator plan

Optional: export to ONNX and run with ONNX Runtime CPU on Fedora.
