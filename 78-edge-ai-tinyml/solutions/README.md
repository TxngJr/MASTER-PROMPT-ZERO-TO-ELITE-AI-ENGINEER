# Chapter 78 Solutions — Key Ideas

- edge feasibility depends on both persistent model storage and peak runtime RAM.
- operator coverage determines whether an accelerator can execute the graph without expensive fallback/partitioning.
- quantization reduces bytes/bandwidth but must be measured for quality and target-kernel support.
- energy/inference combines latency and power; optimize both rather than one in isolation.
- TinyML systems benefit from static memory planning, fixed/ring buffers and small supported operator sets.
