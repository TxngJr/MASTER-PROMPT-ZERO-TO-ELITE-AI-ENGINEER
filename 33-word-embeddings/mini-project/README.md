# Mini Project — Static Embedding Benchmark

Build a small themed corpus.

Train/construct:
- Skip-Gram with Negative Sampling
- GloVe
- FastText-style subword embeddings

Evaluate:
- nearest neighbors
- cosine similarity
- OOV handling
- small downstream classifier
- training time
- embedding dimension
- stability across seeds

Document corpus bias and do not select only flattering examples.
