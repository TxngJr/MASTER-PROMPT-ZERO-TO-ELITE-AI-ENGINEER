# Scientific ML Exercises

## Level 1
1. Define surrogate model.
2. Define physics residual.
3. Define collocation point.
4. Define nondimensionalization.

## Level 2
5. Explain data loss versus physics loss.
6. Explain why boundary conditions matter.
7. Derive the residual for exponential decay du/dt=-k u.
8. Explain interpolation versus extrapolation in parameter space.

## Level 3
9. Implement a centered finite-difference derivative.
10. Implement exponential-decay residual.
11. Compute relative L2 solution error.
12. Build a polynomial surrogate for a simple simulator.

## Level 4
13. Use a coarse grid and quantify derivative error.
14. Create a random-point split that leaks trajectories, then replace it with a trajectory/parameter split.
15. Rescale a badly conditioned physical variable set and compare optimization behavior.
16. Plot residual error and solution error separately.

## Level 5
17. Design a PINN-style objective for a 1D boundary-value problem.
18. Compare a data-only surrogate and physics-regularized surrogate under scarce data.
19. Describe how a neural operator differs from a pointwise regressor.
20. Write a scientific-ML report including units, equations, discretization/reference, splits, residuals, solution error and limitations.
