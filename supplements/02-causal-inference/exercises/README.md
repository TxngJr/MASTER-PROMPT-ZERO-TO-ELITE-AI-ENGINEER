# Causal Inference Exercises

## Level 1
1. Define confounder.
2. Define collider.
3. Define ATE.
4. Define propensity score.

## Level 2
5. Explain association versus intervention.
6. Explain why randomization helps identification.
7. Explain positivity.
8. Explain why conditioning on a collider can induce bias.

## Level 3
9. Compute a difference-in-means estimate.
10. Compute standardized mean difference.
11. Implement clipped inverse-probability weighting.
12. Draw a DAG for treatment, confounder and outcome.

## Level 4
13. Simulate confounding and show naive bias.
14. Create poor overlap and inspect extreme weights.
15. Simulate collider conditioning and observe induced association.
16. Compare adjusted versus unadjusted covariate balance.

## Level 5
17. Write an identification-assumption table.
18. Design an observational study with a justified adjustment set.
19. Propose a sensitivity analysis for an unmeasured confounder.
20. Write a causal report separating assumptions, identification, estimation and uncertainty.
