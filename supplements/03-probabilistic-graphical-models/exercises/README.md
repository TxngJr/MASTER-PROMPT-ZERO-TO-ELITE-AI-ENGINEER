# PGM Exercises

## Level 1
1. Define Bayesian network.
2. Define factor.
3. Define hidden state in an HMM.
4. Define marginal probability.

## Level 2
5. Factor a three-node chain joint distribution.
6. Compare chain, fork and collider conditional independence.
7. Derive one HMM forward step.
8. Explain why variable-elimination order matters.

## Level 3
9. Implement probability normalization.
10. Implement a two-hypothesis Bayes update.
11. Implement the HMM forward algorithm.
12. Enumerate a tiny Bayesian-network marginal.

## Level 4
13. Trigger HMM underflow with a long sequence and design a scaling/log-space fix.
14. Detect a transition matrix whose rows do not sum to one.
15. Compare two variable-elimination orders on factor sizes.
16. Build a message-passing trace for a tree factor graph.

## Level 5
17. Compare exact enumeration with dynamic programming on an HMM.
18. Design a PGM for a sensor-fusion problem.
19. Explain when loopy belief propagation is only approximate.
20. Write an inference report with assumptions, factorization, algorithm, complexity and numerical diagnostics.
