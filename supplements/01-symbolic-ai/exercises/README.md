# Symbolic AI Exercises

## Level 1
1. Define state-space search.
2. Define admissible heuristic.
3. Define CSP.
4. Define Horn rule.

## Level 2
5. Explain BFS vs uniform-cost search.
6. Explain why a zero heuristic makes A-star order by path cost.
7. Explain MRV and least-constraining value.
8. Explain unit propagation.

## Level 3
9. Implement BFS path reconstruction.
10. Implement A-star with non-negative edge costs.
11. Implement map-coloring CSP.
12. Implement Horn forward chaining.

## Level 4
13. Test an overestimating heuristic on a tiny exact graph.
14. Add duplicate-state handling to search.
15. Add forward checking to a CSP.
16. Build and debug a tiny CNF evaluator.

## Level 5
17. Compare node expansions under three heuristics.
18. Encode a tiny planning problem as search.
19. Design a learned-heuristic plus symbolic-verifier hybrid.
20. Compare symbolic guarantees with learned generalization.
