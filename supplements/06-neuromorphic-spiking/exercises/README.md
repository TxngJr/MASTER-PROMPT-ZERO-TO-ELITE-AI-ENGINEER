# Neuromorphic and Spiking Exercises

## Level 1
1. Define spike train.
2. Define membrane potential.
3. Define LIF leak.
4. Define surrogate gradient.

## Level 2
5. Explain rate versus temporal coding.
6. Explain threshold/reset behavior.
7. Derive the no-spike recurrence for constant input.
8. Explain why the hard spike function complicates gradient descent.

## Level 3
9. Implement one LIF step.
10. Simulate multiple neurons over time.
11. Compute firing rate.
12. Plot voltage and spikes for constant versus pulsed input.

## Level 4
13. Create an incorrect reset-order bug and detect it.
14. Sweep beta and explain the change in integration time.
15. Add input noise and measure spike-rate robustness.
16. Compare dense step-by-step computation with an event-count proxy.

## Level 5
17. Compare an ANN baseline and a tiny SNN under matched task/evaluation plus latency accounting.
18. Design a surrogate-gradient experiment and document the surrogate explicitly.
19. Specify what hardware measurements would be needed before claiming energy efficiency.
20. Write a report covering coding, dynamics, training rule, time steps, spikes, accuracy, latency and limitations.
