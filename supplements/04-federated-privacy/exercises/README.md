# Federated and Privacy Exercises

## Level 1
1. Define federated learning.
2. Define FedAvg.
3. Define differential privacy at a conceptual level.
4. Define clipping.

## Level 2
5. Explain example-weighted versus client-weighted averaging.
6. Explain why federated learning is not automatically private.
7. Explain non-IID client data.
8. Distinguish secure aggregation from DP.

## Level 3
9. Implement weighted FedAvg.
10. Implement L2 clipping.
11. Add deterministic Gaussian-noise simulation for a lab.
12. Calculate communication bytes for a fixed-size model update.

## Level 4
13. Construct unequal client sizes and show the error from an unweighted average.
14. Simulate client drift under different local distributions.
15. Vary clipping threshold and measure clipping fraction/utility.
16. Vary lab noise scale and plot the utility trade-off without claiming a privacy budget.

## Level 5
17. Design a federated evaluation table with per-client/group metrics.
18. Write a secure-aggregation threat-model comparison.
19. Specify what evidence is required before reporting an epsilon/delta guarantee.
20. Write a privacy-aware model card section covering data locality, telemetry, aggregation, DP assumptions and limitations.
