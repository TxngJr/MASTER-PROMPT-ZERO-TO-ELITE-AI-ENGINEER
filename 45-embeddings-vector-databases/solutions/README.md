# Chapter 45 Solutions — Key Ideas

- exact search is the quality baseline for ANN evaluation.
- IVF reduces search scope by probing only selected coarse clusters.
- HNSW uses graph navigation to find nearby vectors efficiently.
- PQ compresses vectors into subvector codebook IDs and trades memory for quantization error.
- ANN Recall@K measures agreement with exact retrieval, not end-task answer quality.
