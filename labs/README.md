# Milestone Notebooks

These notebooks are intentionally small and offline-friendly. They are **observation labs**, not replacements for chapter theory or source code.

1. `01-math-numpy.ipynb` — vector/matrix reasoning
2. `02-classical-ml.ipynb` — regression from scratch
3. `03-backprop.ipynb` — numerical derivatives
4. `04-attention-transformer.ipynb` — attention mechanics
5. `05-rag-agents.ipynb` — retrieval and bounded tool schema
6. `06-llm-posttraining.ipynb` — masked token-loss mechanics
7. `07-systems-memory.ipynb` — parameter/KV memory estimates
8. `08-final-llm-capstone.ipynb` — causal-window preparation

For every notebook use the course loop:

~~~text
predict → run → observe → explain → modify → rerun
~~~

Do not treat a successful cell execution as mastery. Link observations back to the relevant chapter tests and mini-project.
