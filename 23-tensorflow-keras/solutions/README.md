# Chapter 23 Solutions — Key Ideas

- tf.Variable stores trainable mutable state.
- GradientTape records differentiable operations.
- Sequential is best for simple stacks; Functional supports DAGs; subclassing offers maximum flexibility.
- SparseCategoricalCrossentropy(from_logits=True) expects raw logits.
- tf.data separates input-pipeline concerns from model logic.
- Keras 3 is an API layer that can run on multiple backends.
