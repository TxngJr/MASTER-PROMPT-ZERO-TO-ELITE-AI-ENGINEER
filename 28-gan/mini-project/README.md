# Mini Project — 2D Distribution GAN

Generate a mixture of several 2D Gaussian clusters.

Train:
- MLP Generator
- MLP Discriminator

Required:
- fixed latent probe
- real/fake scatter plots
- discriminator loss
- generator loss
- generated covariance/mean
- mode-coverage heuristic
- multiple seeds

Extension:
- replace BCE GAN with WGAN-GP and compare stability.
