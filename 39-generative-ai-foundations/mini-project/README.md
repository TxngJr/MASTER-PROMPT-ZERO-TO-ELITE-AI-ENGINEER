# Mini Project — Generative Family Comparison

Use a synthetic multimodal 2D dataset.

Compare:
- single Gaussian maximum likelihood
- Gaussian mixture
- GAN from Batch 10
- diffusion preview/noising diagnostics

Report:
- NLL where available
- mean/covariance
- mode coverage
- nearest-neighbor diagnostics
- generated sample diversity
- training/sampling cost

Explain why one metric cannot fairly compare every generative family.
