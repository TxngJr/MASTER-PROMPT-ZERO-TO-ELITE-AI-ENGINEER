# Chapter 60 Solutions — Key Ideas

- an evaluation score is meaningful only with its model, prompt, tokenizer/template, dataset, decoding and metric protocol.
- use paired sample-level differences when comparing models evaluated on the same items.
- confidence intervals expose uncertainty that point estimates hide.
- calibration, grounding, instruction adherence and systems performance measure different properties.
- exact contamination hashes are useful but cannot detect every paraphrase/near-duplicate leak.
