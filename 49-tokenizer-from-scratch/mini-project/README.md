# Mini Project — Versioned Byte-Level BPE

Train a tokenizer on a multilingual local corpus.

Produce:
- merges.json
- tokenizer_config.json
- corpus hash
- vocabulary size
- reserved special-token IDs
- encode/decode CLI
- compression report

Report:
- bytes/token per language
- token lengths for code/numbers
- roundtrip failures
- sequence-length histogram
