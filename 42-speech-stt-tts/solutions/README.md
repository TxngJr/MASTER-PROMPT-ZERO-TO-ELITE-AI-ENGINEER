# Chapter 42 Solutions — Key Ideas

- STFT represents local frequency content over time.
- mel filter banks compress linear FFT frequencies into perceptually motivated bands.
- CTC learns unknown monotonic alignments by summing over valid blank/repetition paths.
- seq2seq STT uses an audio encoder and autoregressive text decoder instead of CTC's conditional-independence structure.
- TTS often separates linguistic/acoustic prediction from waveform generation through a vocoder.
