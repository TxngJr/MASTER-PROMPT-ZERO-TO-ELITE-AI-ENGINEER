# Mini Project — Synthetic Speech Pipeline

Generate sequences of synthetic tones representing toy phoneme/token IDs.

Build:
- waveform generator
- STFT/log-mel frontend
- acoustic encoder
- CTC output head
- greedy decoder
- token error metric

Then implement a toy inverse mapping from token IDs back to tones to understand the conceptual STT/TTS round trip.

Do not interpret this toy signal generator as real human voice synthesis.
