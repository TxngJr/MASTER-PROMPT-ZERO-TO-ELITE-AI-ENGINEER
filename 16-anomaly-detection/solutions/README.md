# Chapter 16 Solutions — Key Ideas

- Standard z-score is sensitive to contaminated mean/std.
- Median/MAD is more robust to extreme points.
- Mahalanobis uses covariance geometry.
- Isolation Forest isolates sparse points quickly.
- LOF compares local density to neighbors.
- One-Class SVM estimates support of normal data.
- anomaly scores require a threshold/policy before becoming labels.
