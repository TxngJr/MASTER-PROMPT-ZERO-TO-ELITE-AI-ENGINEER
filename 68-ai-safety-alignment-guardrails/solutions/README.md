# Chapter 68 Solutions — Key Ideas

- a system prompt guides a model but cannot replace authentication, authorization or secret management.
- least privilege, permission-aware retrieval, tool-schema validation and explicit approvals reduce the blast radius of model mistakes/injection.
- model output is untrusted data until the next deterministic boundary validates it.
- resource budgets and bounded queues are safety controls for availability/cost as well as performance controls.
- safety evaluation must include benign cases so improvements do not simply come from blocking everything.
