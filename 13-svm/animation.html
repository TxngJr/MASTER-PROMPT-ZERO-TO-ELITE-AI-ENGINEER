1. score ต้องอ่านคู่กับ label

โจทย์และเหตุผล

จุดที่ y(w·x+b) มากกว่า 1 ไม่มี hinge loss แม้จะอยู่ class ถูกเหมือนจุดที่ยังอยู่ใน margin ค่า 0/1 accuracy จึงไม่แสดง geometry ของ margin ครบ

ตัวอย่างและคำอธิบาย

Define margin.

margin เชิงเรขาคณิตของจุดคือ y(wᵀx+b)/‖w‖; w=(2,0), b=0, x=(1,3), y=1 ได้ 1 หน่วย ไม่ใช่ raw score 2

สัญลักษณ์ / input controls

w: weight norm (positive),initial=1; b: bias,initial=0; C: hinge penalty C,initial=1; gamma: RBF gamma,initial=1

8. Soft Margin

เพิ่ม slack variables:

ξ_i >= 0

constraint:

y_i(wᵀx_i+b) >= 1-ξ_i

objective:

min 1/2||w||² + C Σ ξ_i

C ใหญ่: - penalize violations มาก - fit training เข้มขึ้น - regularization อ่อนลงใน common SVM formulation

C เล็ก: - ยอม margin violations มากขึ้น - regularization แรงขึ้น

อธิบายภาษาไทยและตัวอย่างที่ใช้ตรวจความเข้าใจ

soft margin ยอม slack ξ≥0 โดยแก้ ½‖w‖²+CΣξ ภายใต้ yf≥1−ξ; จุดผิดไม่ทำให้ปัญหา infeasible เหมือน hard margin

C สูงเพิ่มต้นทุนของการละเมิด margin จึงอาจตาม outlier มากขึ้น; C ต่ำยอม training errors เพื่อให้ ‖w‖ เล็ก ห้ามสรุปว่า accuracy test เพิ่มเสมอ

9. Hinge Loss

L_i = max(0, 1-y_i f(x_i))

ถ้า:

y_i f(x_i) >= 1

sample อยู่นอก/บน margin ถูกด้าน → hinge loss 0

ถ้าอยู่ใน marginหรือผิดด้าน → positive loss

18. LinearSVC vs SVC

LinearSVC

  • linear only
  • optimized สำหรับ linear SVM
  • scale ได้ดีกว่า kernel SVC บน large/high-dimensional data
  • API/solver formulation ต่างจาก SVC(kernel="linear") บางส่วน

SVC

  • kernelized
  • linear/poly/RBF/custom kernels
  • training cost โตเร็วกับ sample count

"""Educational binary linear SVM using primal subgradient descent."""

from __future__ import annotations

from dataclasses import dataclass, field

import numpy as np


def hinge_loss(
    y_signed: np.ndarray,
    scores: np.ndarray,
) -> float:
    y = np.asarray(y_signed, dtype=float).reshape(-1)
    s = np.asarray(scores, dtype=float).reshape(-1)
    if y.shape != s.shape or y.size == 0:
        raise ValueError("inputs must have equal non-empty shape")
    if not np.all(np.isin(y, [-1.0, 1.0])):
        raise ValueError("labels must be -1/+1")
    return float(np.mean(np.maximum(0.0, 1.0 - y * s)))


@dataclass
class LinearSVMFromScratch:
    C: float = 1.0
    learning_rate: float = 0.02
    steps: int = 3_000
    coef_: np.ndarray | None = None
    intercept_: float | None = None
    classes_: np.ndarray | None = None
    objective_history_: list[float] = field(default_factory=list)

    def fit(self, X: np.ndarray, y: np.ndarray) -> "LinearSVMFromScratch":
        X_array = np.asarray(X, dtype=float)
        y_array = np.asarray(y).reshape(-1)

        if X_array.ndim != 2 or X_array.shape[0] == 0:
            raise ValueError("X must be non-empty 2D")
        if X_array.shape[0] != y_array.shape[0]:
            raise ValueError("X/y sample counts differ")
        if not np.all(np.isfinite(X_array)):
            raise ValueError("X must be finite")
        if self.C <= 0 or self.learning_rate <= 0 or self.steps <= 0:
            raise ValueError("C, learning_rate and steps must be positive")

        classes = np.unique(y_array)
        if classes.size != 2:
            raise ValueError("educational implementation supports binary labels")

        self.classes_ = classes
        signed = np.where(y_array == classes[0], -1.0, 1.0)

        n_samples, n_features = X_array.shape
        w = np.zeros(n_features, dtype=float)
        b = 0.0
        self.objective_history_ = []

        for step in range(self.steps):
            scores = X_array @ w + b
            margins = signed * scores
            active = margins < 1.0

            grad_w = w.copy()
            grad_b = 0.0

            if np.any(active):
                grad_w -= (
                    self.C / n_samples
                ) * (X_array[active].T @ signed[active])
                grad_b -= (
                    self.C / n_samples
                ) * float(np.sum(signed[active]))

            # Mild inverse-time decay stabilizes the simple subgradient solver.
            eta = self.learning_rate / (1.0 + 0.0005 * step)
            w -= eta * grad_w
            b -= eta * grad_b

            hinge = hinge_loss(signed, X_array @ w + b)
            objective = 0.5 * float(w @ w) + self.C * hinge
            self.objective_history_.append(objective)

        self.coef_ = w
        self.intercept_ = b
        return self

    def decision_function(self, X: np.ndarray) -> np.ndarray:
        if self.coef_ is None or self.intercept_ is None:
            raise RuntimeError("model must be fit before prediction")
        X_array = np.asarray(X, dtype=float)
        if X_array.ndim != 2 or X_array.shape[1] != self.coef_.shape[0]:
            raise ValueError("feature shape differs from fitted model")
        return X_array @ self.coef_ + self.intercept_

    def predict(self, X: np.ndarray) -> np.ndarray:
        if self.classes_ is None:
            raise RuntimeError("model must be fit before prediction")
        signed = np.where(self.decision_function(X) >= 0.0, 1, -1)
        return np.where(signed == -1, self.classes_[0], self.classes_[1])

เทนเซอร์: ชุดตัวเลขที่มีแกน เช่น scalar ไม่มีแกน, vector หนึ่งแกน, matrix สองแกน; shape บอกขนาดแต่ละแกน ไม่บอกความหมายของแกนจนกว่าจะระบุ
shape
รูปทรงข้อมูล: (B,T,d) หมายถึง batch × เวลา/ตำแหน่ง × features; ใช้ชื่อแกนกำกับเสมอ การ transpose เปลี่ยนแกนแต่ไม่ใช่แค่เปลี่ยนชื่อ
batch
กลุ่มตัวอย่างที่คำนวณร่วมกันหนึ่งครั้ง; B คือจำนวนตัวอย่าง ไม่ใช่จำนวน features หรือจำนวน optimizer updates
weight w / θ
น้ำหนักหรือพารามิเตอร์ที่โมเดลใช้คำนวณ; แก้ด้วยมือทำ forward ใหม่ ส่วน optimizer ต้องรับ gradient แล้วกด update จึงแก้ state
bias b
ค่าคงที่ที่บวกกับผลเชิงเส้น; regression scalar bias เพิ่ม Δ ทำให้ prediction ทุกจุดเพิ่ม Δ เท่ากัน
prediction ŷ
ค่าที่โมเดลทำนายจาก input และพารามิเตอร์ปัจจุบัน; เครื่องหมายหมวกแยกจาก target y ที่มาจากข้อมูล
residual e
ความคลาดเคลื่อน ในเว็บนี้นิยาม prediction − target; บางตำราใช้เครื่องหมายกลับกัน จึงต้องตรวจนิยามก่อนเทียบสูตร gradient
MSE
mean squared error = ผลรวม residual กำลังสองหารจำนวนรายการที่ระบุ; มีหน่วยเป็น target ยกกำลังสอง และการใช้ sum แทน mean เปลี่ยน scale gradient
loss L / objective J
จำนวนที่ optimizer ต้องการลด; objective อาจรวม data loss และ regularization จึงต้องดูองค์ประกอบและ reduction ให้ตรง implementation
gradient ∇ / ∂
เวกเตอร์ของ partial derivatives บอกอัตราเปลี่ยน loss ต่อพารามิเตอร์แต่ละตัว; ∂ ใช้เมื่อเปลี่ยนตัวหนึ่งโดยตรึงตัวอื่น
chain rule
กฎลูกโซ่: คูณอนุพันธ์ตามเส้นทาง และบวก contribution จากทุกเส้นทางที่มารวมกัน ใช้ย้อนจาก loss ถึง weights
learning rate η
ขนาดตัวคูณ gradient ใน update θnew=θ−ηg; η≥0, ศูนย์หมายถึงไม่มีการขยับพารามิเตอร์ ก้าวใหญ่เกินอาจ diverge
regularization λ
ตัวคูณค่าลงโทษ ต้อง λ≥0 ตามนิยามการลงโทษ; Ridge λΣw² เพิ่ม gradient 2λw โดยบท Regression นี้ไม่ลงโทษ bias
baseline
สถานะอ้างอิงที่ตรึงไว้สำหรับเทียบ; ต้องเก็บ snapshot ไม่อ้าง object ปัจจุบันที่แก้ตามไปด้วย
invariant
คุณสมบัติที่กลไกต้องรักษา เช่น probability รวม1, shape สอดคล้อง, queue ไม่เกิน capacity; ใช้ tests ตรวจได้มากกว่าดูภาพสวย
optimizer state
ความจำของอัลกอริทึม เช่น velocity, moments และ completed updates; คืนเฉพาะ weights ยังไม่เท่ากับเริ่มการฝึกใหม่ทั้งหมด
finite difference
ประมาณ derivative ด้วย [f(x+h)−f(x−h)]/(2h); h>0, ใช้ smooth point และลองหลาย h เพื่อแยก truncation error จาก roundoff
softmax
แปลง logits เป็นความน่าจะเป็นตามแกนที่กำหนด; ลบ max ก่อน exp เพื่อความเสถียร และ fully masked row ต้องมีนโยบายชัดเจน
logit
คะแนนก่อน sigmoid/softmax ไม่ใช่ probability; อาจเป็นจำนวนจริงติดลบหรือเกิน1ได้ จึงห้ามส่งให้ loss ที่คาด probability โดยไม่แปลง
temperature τ / T
ตัวหาร logits ก่อน softmax; ต้องเป็นบวก ค่าเล็กทำ distribution แหลมขึ้น โดยไม่เท่ากับ retrain weights
mask
ตัวกำหนดตำแหน่งที่อ่านหรือคิด loss ได้; causal mask ปิดอนาคต, padding mask ปิดข้อมูลเติม, loss mask เลือก target แต่ละอย่างคนละหน้าที่
Q / K / V
query ใช้ค้นข้อมูล, key ใช้จับคู่ query, value เป็นข้อมูลที่ถูกถัวเฉลี่ย; เป็น learned projections ของ representation ไม่ใช่ป้ายความหมายตายตัว
head
ส่วนของ feature representation ที่ทำ attention แยกกัน แล้ว concat/project กลับ; ต้องตรวจ d_model หารจำนวน heads ลงตัว
ε-neighborhood
เพื่อนบ้านทั้งหมดที่มีระยะไม่เกิน ε รวมจุดตัวเองใน DBSCAN นี้; ε มีหน่วยเดียวกับพิกัด ไม่ใช่จำนวน k ที่ใช้โหวต
core / border / noise
DBSCAN core มีเพื่อนบ้านรวมตัวเองถึง min_samples; border อยู่ใกล้ core แต่เพื่อนบ้านไม่ถึง; noise ไม่ถูกเชื่อมกับ core cluster ใด
bootstrap
สุ่ม observations แบบ replacement ขนาดเท่าเดิมซ้ำหลายครั้งแล้วคำนวณ statistic ใหม่; seed ทำให้ตรวจซ้ำได้ แต่ไม่แก้สมมติฐาน IID ที่ผิด
confidence interval
ช่วงที่สร้างด้วย procedure ที่มี coverage ตามสมมติฐาน; ช่วงหนึ่งที่ได้แล้วไม่ใช่ posterior probability ของ parameter และ sample เล็กยังไม่แน่นอนมาก
validation / test
validation ใช้เลือกโมเดล/ค่าตั้ง ส่วน test ใช้ประเมินหลัง freeze การตัดสินใจ; fit preprocessing/tokenizer จาก test เป็น leakage
leakage
ข้อมูลที่ควรยังไม่รู้ไหลเข้า training/การเลือกโมเดล เช่น future feature หรือเอกสารซ้ำข้าม split ทำให้ metric ดูดีเกินการใช้งานจริง
queue / capacity
queue คือรายการรอ, capacity การให้บริการรวม = workers × service rate ตามแบบจำลอง; เพิ่ม timeout ไม่เพิ่มกำลังประมวลผล
state transition
การเปลี่ยนสถานะเมื่อเกิดเหตุการณ์ที่อนุญาต เช่น queued→active→done; ต้องระบุ guard, side effect และเหตุผลเมื่อ transition ถูกปฏิเสธ
latency / throughput
latency คือเวลาต่อคำขอ, throughput คือปริมาณงานต่อหน่วยเวลา; batching อาจเพิ่ม throughput แต่เพิ่มเวลารอ จึงต้องวัดทั้งคู่
idempotency
ทำคำขอ business operation เดิมซ้ำแล้ว side effect เกิดครั้งเดียวตาม key และ transaction protocol; ไม่ได้รับประกันจากการใช้ UUID ใหม่ทุก attempt
local lab
โปรแกรม Python และ tests ที่ผู้เรียนรันบนเครื่อง; เว็บเก็บเพียงคำยืนยันของผู้เรียน การผ่าน tests ของโค้ดต้นแบบไม่ใช่ผลตรวจโค้ดผู้เรียน
