# Mini Project — Representation Geometry Lab

Use a dataset with 10+ numeric features.

## Part A — PCA

1. split data
2. fit StandardScaler on train
3. fit PCA on train
4. explained variance curve
5. reconstruction error vs k
6. downstream classifier score vs k

## Part B — Visualization

Compare:
- first 2 raw standardized features
- PCA 2D
- t-SNE 2D
- optional UMAP 2D

Repeat seeds/hyperparameters.

## Part C — Clustering After Reduction

Compare K-Means before/after PCA.

Do not claim better semantic clustering merely because 2D plot looks cleaner; use quantitative and domain checks.
