# Chapter 15 Solutions — Key Ideas

- PCA maximizes projected variance under unit/orthogonal constraints.
- Covariance eigenvectors are principal directions.
- For centered X = UΣVᵀ, PCA directions are rows of Vᵀ.
- eigenvalue = singular_value²/(n-1).
- PCA centers but does not automatically standardize feature scales.
- t-SNE/UMAP visualizations require cautious interpretation.

A 2D visualization is an analysis aid, not proof of true clusters.
