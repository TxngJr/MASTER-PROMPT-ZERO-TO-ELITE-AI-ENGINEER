# Chapter 69 Solutions — Key Ideas

- different explanation methods answer different questions and make different assumptions.
- Integrated Gradients depends on the baseline and should be checked with its completeness/convergence behavior.
- exact Shapley values are exponential in feature count, so practical SHAP implementations use specialized/approximate algorithms.
- correlated features complicate both coefficient and permutation interpretations.
- explanations should be tested for faithfulness/stability and should not automatically be interpreted as causal mechanisms.
