# Mini Project — Explanation Reliability Audit

Train a small tabular model and produce:
- permutation importance
- local numerical saliency
- Integrated Gradients for a differentiable toy equivalent
- occlusion importance
- exact Shapley values for a reduced 3–5 feature version

Then audit:
- correlated features
- baseline sensitivity
- attribution stability
- random-feature ablation
- explanation completeness

Write a final section separating predictive explanation claims from causal claims.
