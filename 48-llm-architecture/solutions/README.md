# Chapter 48 Solutions — Key Ideas

- RMSNorm scales by root-mean-square magnitude without subtracting the mean.
- RoPE rotates Q/K feature pairs using position-dependent frequencies.
- GQA keeps many query heads while sharing fewer K/V heads, reducing KV-cache storage.
- causal SDPA applies future masking before softmax.
- SwiGLU gates one learned projection with SiLU before multiplying another projection.
