# Mini Project — Instruction SFT Lab

Create a small multilingual instruction dataset with train/validation/test prompt families.

Build:
- messages schema
- chat formatting
- byte/token encoding
- assistant-only labels
- truncation audit
- SFT dataloader
- full fine-tuning baseline
- LoRA SFT variant

Evaluate:
- held-out exact tasks
- formatting compliance
- supervised-token utilization
- trainable parameter count
- validation loss
- base-capability retention
