# Mini Project — Tiny GPT

Use a small internal text corpus.

Build:
- vocabulary
- context windows
- decoder-only Transformer
- causal self-attention
- vocabulary head
- next-token cross-entropy
- validation perplexity
- generation

Generation modes:
- greedy
- temperature
- top-k
- top-p

Extension:
- implement KV cache for one attention layer and compare outputs with naive full-prefix generation.
