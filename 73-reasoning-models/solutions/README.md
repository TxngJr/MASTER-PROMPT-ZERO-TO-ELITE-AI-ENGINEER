# Chapter 73 Solutions — Key Ideas

- reasoning quality must be compared under explicit token/latency/compute budgets.
- self-consistency aggregates independently sampled outputs; it cannot fix systematic errors shared by all samples.
- best-of-N transfers selection risk to the verifier.
- pass@k is a combinatorial probability metric, not top-k classification accuracy.
- generated reasoning traces are useful observable artifacts but should not automatically be treated as faithful hidden computation.
