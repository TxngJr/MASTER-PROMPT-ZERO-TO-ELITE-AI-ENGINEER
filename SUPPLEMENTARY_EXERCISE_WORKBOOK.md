# Supplementary Exercise Workbook — Chapters 13–78

This workbook supplies Exercises 11–20 for chapters whose original exercise file historically contained only ten questions. If a chapter exercise file has already been expanded to twenty questions, use this workbook as an additional mastery set rather than double-counting.

## 13-svm — SVM

### Applied Practice
11. Reproduce one central calculation from SVM using a tiny hand-checkable input.
12. Write a deterministic test that verifies the most important invariant in SVM.
13. Compare two meaningful configurations while keeping data and seed fixed.
14. Record intermediate shapes, ranges, and one quality metric for a tiny end-to-end run.
15. Explain one evaluation mistake that could make a SVM result look better than it really is.

### Advanced Practice
16. State the dominant time and memory complexity for the main operation in SVM.
17. Compare a from-scratch result with a trusted implementation using identical inputs and settings.
18. Run a one-factor ablation and report the measured change over repeated runs when randomness matters.
19. Design a small reproducibility record containing seed, code version, data version, configuration, and metric.
20. Propose one falsifiable research question for SVM and specify the baseline, changed factor, and acceptance metric.

### Expected Solution Checks
- 11: expose the mechanism instead of delegating the whole task to one high-level helper.
- 12: include a normal case and an edge case with explicit expected behavior.
- 13: change one factor only.
- 14: record enough intermediate state to locate the first unexpected value.
- 15: preserve held-out evaluation data and fit learned preprocessing only on training data.
- 16: identify dominant operations and separate algorithmic complexity from framework overhead.
- 17: align seed, preprocessing, parameter values, reduction conventions, and numeric precision.
- 18: report the measured difference; do not rely on one favorable run.
- 19: another learner must be able to identify the exact experiment.
- 20: include baseline, controlled change, metric, and interpretation criterion.
