# Mini Project — Local Grounded QA

Create a local knowledge corpus of Markdown documents.

Build:
- parser
- chunker
- metadata
- simple embeddings
- exact vector index
- keyword retriever
- RRF fusion
- MMR/reranking
- context packing
- grounded answer template with source IDs

Evaluate:
- retrieval Recall@K
- MRR
- answer correctness
- citation correctness
- insufficient-evidence handling
