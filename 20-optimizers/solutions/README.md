# Chapter 20 Solutions — Key Ideas

- SGD follows the negative gradient.
- Momentum accumulates a velocity-like state.
- AdaGrad accumulates all historical squared gradients.
- RMSProp uses an exponential moving average instead.
- Adam tracks first and second moments plus bias correction.
- AdamW applies weight decay separately from the adaptive gradient calculation.
- zero_grad is necessary because backprop gradients accumulate.
