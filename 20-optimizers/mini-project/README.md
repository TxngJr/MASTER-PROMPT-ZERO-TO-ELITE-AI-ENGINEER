# Mini Project — Optimizer Landscape Lab

Optimize the same objectives with:
- SGD
- Momentum
- Nesterov
- AdaGrad
- RMSProp
- Adam
- AdamW

Objectives:
1. 1D quadratic
2. ill-conditioned 2D quadratic
3. Rosenbrock function

Record:
- loss per step
- parameter trajectory
- gradient norm
- optimizer-state bytes
- sensitivity to learning rate

Do not declare a universal optimizer winner; compare behavior under controlled settings.
