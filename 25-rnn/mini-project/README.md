# Mini Project — Sequence Memory Lab

Generate binary/numeric sequences where the target depends on information several steps back.

Compare:
- MLP on flattened fixed window
- vanilla RNN
- later LSTM/GRU

Required:
- sequence length sweep
- hidden-size sweep
- gradient norm tracking
- clipping on/off
- train/validation curves
- causal vs bidirectional discussion

Goal: observe where vanilla RNN memory/optimization begins to break.
