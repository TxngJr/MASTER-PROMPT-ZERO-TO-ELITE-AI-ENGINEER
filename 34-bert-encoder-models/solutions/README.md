# Chapter 34 Solutions — Key Ideas

- BERT-style encoders use full bidirectional attention over valid tokens.
- MLM loss is computed only on selected prediction positions.
- original BERT corrupts selected tokens with an 80% mask / 10% random / 10% unchanged policy.
- CLS is a learned pooling convention rather than a privileged mathematical operator.
- NSP is historically part of original BERT but not required by all later encoders.
