# Chapter 18 Solutions — Key Ideas

- neuron preactivation is z = w^T x + b
- dense batch form is XW+b
- stacked linear layers without nonlinear activation collapse to one linear transform
- parameter count includes biases
- ReLU creates piecewise-linear nonlinearity
- sigmoid maps logits to (0,1)
- softmax must subtract max for stability
- forward pass computes values; training additionally requires gradients and updates
