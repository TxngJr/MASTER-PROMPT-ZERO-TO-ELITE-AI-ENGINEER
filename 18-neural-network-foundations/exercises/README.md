# Neural Network Foundations — Exercises

## Level 1 — Recall
1. Define neuron.
2. Define linear layer with a small example.
3. Explain activation.
4. Explain forward pass.

## Level 2 — Understanding
5. Compare neuron and linear layer.
6. Explain how forward pass changes model behavior.
7. Explain a common limitation involving parameter initialization.
8. Explain the tradeoff introduced by batching.

## Level 3 — Coding
9. Implement a small from-scratch example of neuron.
10. Add deterministic tests for Exercise 9.
11. Implement the main computation behind activation.
12. Run a small seeded experiment using linear layer, forward pass, and batching.

## Level 4 — Analysis
13. Explain a common shape or data mismatch for this topic.
14. Explain one numerical-stability concern.
15. Explain the correct train, validation, and test workflow.
16. Measure runtime and memory of the main computation.

## Level 5 — Challenge
17. Derive the main input-to-output algorithm for Neural Network Foundations.
18. Compare a scratch implementation with a trusted library on identical data.
19. Compare a baseline with a controlled change involving parameter initialization.
20. Summarize validation, reproducibility, monitoring, and one open research question.
