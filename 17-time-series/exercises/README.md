# Time Series — Exercises

## Level 1 — Recall
1. Define trend.
2. Define seasonality with a small example.
3. Explain stationarity.
4. Explain autocorrelation.

## Level 2 — Understanding
5. Compare trend and seasonality.
6. Explain how autocorrelation changes model behavior.
7. Explain a common limitation involving ARIMA.
8. Explain the tradeoff introduced by walk-forward validation.

## Level 3 — Coding
9. Implement a small from-scratch example of trend.
10. Add deterministic tests for Exercise 9.
11. Implement the main computation behind stationarity.
12. Run a small seeded experiment using seasonality, autocorrelation, and walk-forward validation.

## Level 4 — Analysis
13. Explain a common shape or data mismatch for this topic.
14. Explain one numerical-stability concern.
15. Explain the correct train, validation, and test workflow.
16. Measure runtime and memory of the main computation.

## Level 5 — Challenge
17. Derive the main input-to-output algorithm for Time Series.
18. Compare a scratch implementation with a trusted library on identical data.
19. Compare a baseline with a controlled change involving ARIMA.
20. Summarize validation, reproducibility, monitoring, and one open research question.
