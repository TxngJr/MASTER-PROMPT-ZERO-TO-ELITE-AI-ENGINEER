# Mini Project — Cluster Assumption Lab

Generate datasets:
- spherical blobs
- anisotropic blobs
- moons
- unequal-density blobs
- noise/outliers

Compare:
- KMeans
- DBSCAN
- AgglomerativeClustering
- GaussianMixture

For each:
1. same standardized representation where appropriate
2. plot clusters
3. silhouette where meaningful
4. noise count
5. runtime
6. repeat seeds for randomized models

Write which algorithm assumption matches each geometry and where metrics mislead.
