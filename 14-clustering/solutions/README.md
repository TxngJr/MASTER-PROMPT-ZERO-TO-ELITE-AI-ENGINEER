# Chapter 14 Solutions — Key Ideas

- K-Means minimizes within-cluster squared distance.
- Lloyd alternates assignments and centroid means.
- K-Means++ spreads initial centers using squared-distance-weighted sampling.
- DBSCAN does not require K but depends strongly on eps/min_samples.
- Agglomerative clustering builds a merge hierarchy.
- GMM uses soft responsibilities and EM.

Cluster labels themselves have no numeric order.
