# Chapter 76 Solutions — Key Ideas

- useful world models predict task-relevant future structure, not necessarily exact pixels.
- action-conditioned dynamics are essential when planning controllable interventions.
- multi-step error matters because one-step errors compound during imagination.
- receding-horizon replanning reduces dependence on long inaccurate open-loop rollouts.
- a planner can exploit model errors, so imagined reward must be validated against real/simulated ground truth.
