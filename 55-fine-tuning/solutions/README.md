# Chapter 55 Solutions — Key Ideas

- full fine-tuning updates every parameter and offers maximum adaptation capacity at maximum training/state cost.
- freezing reduces trainable state and can preserve representations when data is small.
- checkpoint and hyperparameter decisions belong on validation data, never final test data.
- catastrophic forgetting is measured by capability loss outside the target task, not just target-task training loss.
- always compare against a no-adaptation/base-model baseline.
