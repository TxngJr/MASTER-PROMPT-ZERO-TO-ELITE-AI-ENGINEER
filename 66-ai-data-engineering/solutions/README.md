# Chapter 66 Solutions — Key Ideas

- partition keys should support common pruning while avoiding extreme cardinality/tiny files.
- event time, processing time and watermark policy must be explicit in streaming systems.
- retries require idempotent identities or transactional sinks to avoid duplicate logical output.
- schema compatibility includes semantics, not only physical readability.
- immutable/reconstructable data snapshots and lineage are required for reproducible ML training.
