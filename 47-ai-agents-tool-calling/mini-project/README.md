# Mini Project — Safe Research Agent

Build an agent with only:
- local document search
- chunk fetch
- calculator
- final answer

Requirements:
- strict tool schemas
- read-only registry
- max-step limit
- structured result envelopes
- source tracking
- malformed-call tests
- prompt-injection test documents
- action trace evaluation

Then add a separate write tool behind an explicit approval flag and demonstrate that it remains blocked by default.
