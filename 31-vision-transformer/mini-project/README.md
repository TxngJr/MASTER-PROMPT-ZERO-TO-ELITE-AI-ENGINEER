# Mini Project — Tiny ViT vs CNN

Use sklearn digits.

Train:
- a small CNN baseline
- a tiny ViT

Use exactly the same:
- train/validation/test split
- normalized images
- epoch budget
- model-selection protocol

Report:
- parameter count
- validation accuracy
- test accuracy
- runtime
- patch size
- token count

Do not claim ViT is better/worse universally from this small dataset; analyze inductive bias and data scale.
