# Mini Project — Attention Microscope

Create short synthetic token sequences.

Implement and inspect:
- single-head attention
- multi-head attention
- causal attention
- cross-attention extension

Report:
- Q/K/V shapes
- score matrices
- mask matrices
- attention row sums
- entropy
- output shapes
- runtime vs sequence length

Then compare the NumPy output against PyTorch scaled_dot_product_attention for equivalent tensors.
