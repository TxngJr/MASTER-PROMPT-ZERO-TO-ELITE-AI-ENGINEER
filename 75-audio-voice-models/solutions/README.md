# Chapter 75 Solutions — Key Ideas

- audio token rate and codec bitrate directly influence generative audio compute/bandwidth.
- VAD and endpointing affect conversational latency even when ASR accuracy is unchanged.
- RTF measures processing speed relative to audio duration; it does not equal time-to-first-response.
- full-duplex voice adds echo, overlap, cancellation and synchronization problems beyond STT/TTS.
- evaluate streaming partial behavior and turn-taking in addition to final transcription/synthesis quality.
