# Chapter 70 Solutions — Key Ideas

- unstructured pruning produces sparse connectivity but not necessarily smaller dense tensor shapes.
- structured pruning removes hardware-friendly units such as rows/channels/heads.
- knowledge distillation transfers probability/representation information from teacher to student.
- temperature reveals softer class relationships; the common KL formulation multiplies by T^2.
- evaluate final compressed artifacts for task quality, bytes, memory and real latency.
