# Mini Project — CNN Shape & Performance Lab

Use sklearn digits or another small image dataset.

Build equivalent small CNNs in:
- PyTorch
- TensorFlow/Keras

Required:
1. same train/validation/test indices
2. equivalent convolution channel counts
3. equivalent output logits
4. validation model selection
5. final test once
6. parameter count
7. fit/predict runtime
8. confusion matrix
9. CPU run
10. GPU run when available

Do not compare framework speed unless preprocessing, batch size, model, warmup, and synchronization behavior are accounted for.
