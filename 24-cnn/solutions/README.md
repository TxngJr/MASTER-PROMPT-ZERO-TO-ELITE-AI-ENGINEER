# Chapter 24 Solutions — Key Ideas

- output spatial size depends on input, padding, effective kernel, stride.
- convolution kernels span all input channels.
- parameter sharing is the key reason convolution can be parameter-efficient.
- PyTorch commonly uses NCHW; Keras commonly defaults to NHWC.
- global average pooling can dramatically reduce classifier-head parameters.
- a visually clean feature map is not proof of semantic interpretation.
