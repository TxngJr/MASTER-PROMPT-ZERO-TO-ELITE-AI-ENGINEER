1. หนึ่งช่อง output มาจาก patch หนึ่งบริเวณ

โจทย์และเหตุผล

คูณ pixel กับ kernel ตำแหน่งเดียวกันแล้วรวมบวก bias ภาพแสดงทุก product ในตาราง การเปลี่ยน kernel weight เดียวมีผลกับทุกตำแหน่งที่ใช้ weight นั้น เป็นที่มาของ weight sharing

ตัวอย่างและคำอธิบาย

Implement a small example of convolution.

สัญลักษณ์ / input controls

position: output position index,initial=0; kernelWeight: kernel top-right weight,initial=1; pixel: input center pixel,initial=1; bias: convolution bias,initial=0; stride: stride,initial=1; padding: zero padding,initial=0

แทนค่าจริงทีละ operation

  1. Hout=floor((5+2p−3)/stride)+1; index∈[0,8] = [3, 3, 0, 0, 0]; ไม่วน index กลับ; row=floor(index/Hout),col=index mod Hout หลังตรวจขอบเขต
  2. patch[a,b]=Xpad[0+a,0+b] = [[0, 0, 1], [0, 0, 1], [0, 0, 1]]; คูณ stride ก่อนเลือกจุดเริ่ม แล้วอ่าน 3×3; padding เป็นศูนย์ที่ขอบ

  5. Y[row,col] ← selected output = [[3, 3, 0], [3, 3, 0], [3, 3, 0]]; เดินทุก valid output position ด้วยกฎเดียวกัน; tensor output ใช้ค่าคำนวณชุดเดียวกับกราฟ

3. Convolution vs Cross-Correlation

Deep-learning libraries usually implement cross-correlation:

output[i,j]
=
sum over kernel window:
input[i+u,j+v] * kernel[u,v]

Classical mathematical convolution flips the kernel first.

In deep learning, learned kernels make this naming distinction less important operationally, but you should know it.

3. Convolution vs Cross-Correlation

Deep-learning libraries usually implement cross-correlation:

output[i,j]
=
sum over kernel window:
input[i+u,j+v] * kernel[u,v]

Classical mathematical convolution flips the kernel first.

In deep learning, learned kernels make this naming distinction less important operationally, but you should know it.

Larger stride: - lower compute - lower spatial resolution - may discard details

"""Educational NCHW convolution and pooling implemented with NumPy loops."""

from __future__ import annotations

import numpy as np


def conv_output_size(
    input_size: int,
    kernel_size: int,
    *,
    stride: int = 1,
    padding: int = 0,
    dilation: int = 1,
) -> int:
    if min(input_size, kernel_size, stride, dilation) <= 0 or padding < 0:
        raise ValueError("invalid convolution dimensions")
    effective = dilation * (kernel_size - 1) + 1
    output = (input_size + 2 * padding - effective) // stride + 1
    if output <= 0:
        raise ValueError("kernel is larger than padded input")
    return output


def conv2d_nchw(
    x: np.ndarray,
    weight: np.ndarray,
    bias: np.ndarray | None = None,
    *,
    stride: int = 1,
    padding: int = 0,
) -> np.ndarray:
    inputs = np.asarray(x, dtype=float)
    kernels = np.asarray(weight, dtype=float)

    if inputs.ndim != 4 or kernels.ndim != 4:
        raise ValueError("x and weight must be rank-4 NCHW/OIHW arrays")

    n, c_in, h, w = inputs.shape
    c_out, kernel_c_in, kh, kw = kernels.shape

    if c_in != kernel_c_in:
        raise ValueError("input channel count does not match kernel")
    if stride <= 0 or padding < 0:
        raise ValueError("invalid stride/padding")

    if bias is None:
        biases = np.zeros(c_out, dtype=float)
    else:
        biases = np.asarray(bias, dtype=float).reshape(-1)
        if biases.shape != (c_out,):
            raise ValueError("bias must have shape (out_channels,)")

    h_out = conv_output_size(h, kh, stride=stride, padding=padding)
    w_out = conv_output_size(w, kw, stride=stride, padding=padding)

    padded = np.pad(
        inputs,
        ((0, 0), (0, 0), (padding, padding), (padding, padding)),
        mode="constant",
    )
    output = np.empty((n, c_out, h_out, w_out), dtype=float)

    for batch in range(n):
        for out_channel in range(c_out):
            for out_y in range(h_out):
                y0 = out_y * stride
                for out_x in range(w_out):
                    x0 = out_x * stride
                    window = padded[
                        batch,
                        :,
                        y0 : y0 + kh,
                        x0 : x0 + kw,
                    ]
                    output[batch, out_channel, out_y, out_x] = (
                        np.sum(window * kernels[out_channel])
                        + biases[out_channel]
                    )

    return output


def max_pool2d_nchw(
    x: np.ndarray,
    *,
    kernel_size: int = 2,
    stride: int | None = None,
) -> np.ndarray:
    inputs = np.asarray(x, dtype=float)
    if inputs.ndim != 4:
        raise ValueError("x must be rank-4 NCHW")

    if stride is None:
        stride = kernel_size

    if kernel_size <= 0 or stride <= 0:
        raise ValueError("kernel_size and stride must be positive")

    n, channels, h, w = inputs.shape
    h_out = conv_output_size(h, kernel_size, stride=stride)
    w_out = conv_output_size(w, kernel_size, stride=stride)

    output = np.empty((n, channels, h_out, w_out), dtype=float)

    for batch in range(n):
        for channel in range(channels):
            for out_y in range(h_out):
                y0 = out_y * stride
                for out_x in range(w_out):
                    x0 = out_x * stride
                    window = inputs[
                        batch,
                        channel,
                        y0 : y0 + kernel_size,
                        x0 : x0 + kernel_size,
                    ]
                    output[batch, channel, out_y, out_x] = np.max(window)

    return output

Batch 08 Integration Project — Cross-Framework CNN Lab

This project trains equivalent small CNN classifiers on the same sklearn digits dataset using:

  • PyTorch
  • TensorFlow/Keras

The goal is not to declare a framework winner. The goal is to understand how the same mathematical model maps to different framework APIs.

Shared Protocol

sklearn digits
→ fixed stratified split
→ normalize pixels to [0,1]
→ same train / validation / test indices
→ equivalent small CNNs
→ validation tracking
→ final test

Data Layout

PyTorch branch:

N × C × H × W

TensorFlow/Keras branch:

N × H × W × C

The conversion is explicit.

Run PyTorch

Install the core course environment first:

python -m pip install -r requirements-batch08.txt

Then install PyTorch using the current official selector for your machine.

Run:

python integration-project-batch08/src/cnn_framework_lab.py \
  --framework pytorch \
  --epochs 8 \
  --output-dir reports/batch08-pytorch

Run TensorFlow/Keras

CPU/simple install:

python -m pip install -r requirements-batch08-tensorflow.txt

On a compatible NVIDIA Linux GPU environment, follow the current TensorFlow Linux GPU installation instructions instead of assuming an old CUDA setup.

python integration-project-batch08/src/cnn_framework_lab.py \
  --framework tensorflow \
  --epochs 8 \
  --output-dir reports/batch08-tensorflow
